# Homework Skill — ChatGPT 优先版

## 当前状态
v0.2.0 指令包：智能混合模式、作业理解、按需检索、原创构思、学科辅导、文件交付与质量校验。该版本是**可使用的工作流规范**，不是已独立部署的软件，也尚未经过真实作业端到端验收。

## 智能混合工作机制
- 明确简单任务：直接生成。
- 创意开放、材料与耗时差异大的任务：提供2–3个方案并推荐，选定后生成。
- 老师关键要求缺失：只询问不可推断的必要信息。
- 用户说“直接做”：在不违反约束的情况下立即制作。
- 后续说“换黑白打印/材料替换”：保留其它要求，局部调整。

## 如何在ChatGPT中使用
将 SKILL.md 和相关模块内容作为 Homework 项目的知识/指令提供给 ChatGPT；GitHub 文件提交本身**不会自动安装或触发**Skill。实际生成图片/PDF/Word和检索内容取决于当前会话有无对应工具。不能保证读取小红书、公众号、视频号等需权限的平台内容。

## 验收案例
1. 一年级A4秋天手抄报，直接制作黑白可打印底稿。
2. 用常见材料完成秋季立体手工，先给不同成本的方案。
3. 老师指定词表做拼音卡但词表缺失，仅追问词表。
4. 制作20以内加减法十题练习和独立答案页。
