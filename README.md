# Homework Skill — ChatGPT 优先版

面向小学一年级及低年级家长，将老师布置的作业转成可执行方案与可打印完成包。

## 能力
- 智能理解作业通知（文字、图片、文档）
- 五种自动组合模式：创意、手工、学科、研究、文档
- 按需搜索可访问的公开来源，原创设计多套方案
- 步骤指导、亲子分工、家庭常备材料替代
- 利用ChatGPT当前可用工具实际生成图片、PDF、Word、打印模板

## 如何使用
将仓库中的 `SKILL.md` 和参考文件加载到支持自定义Skills的环境；如果当前ChatGPT项目暂不支持直接安装，复制核心指令到项目指令中，或在对话中提供这些文件作为任务依据。**上传GitHub并不等于安装到ChatGPT。**

示例：“一年级秋天主题树叶画，只有树叶、胶棒、A4纸，直接给我完整方案和可打印模板。”

## 文件
- `SKILL.md`：工作流
- `references/quality-checklist.md`：质量检查
- `references/family-profile.example.md`：可手工更新的偏好
- `templates/homework-package.md`：标准输出模板

## 边界
不保证直接读取小红书、公众号或视频号私域内容；不自动长期记忆个人偏好；生成成果取决于当前ChatGPT工具权限。
